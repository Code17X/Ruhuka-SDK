# SDK / Adaptive Agent Role

Read before coding.

## Own

- browser SDK
- website scanning
- semantic representation
- adaptation
- theme adaptation
- self-healing
- adaptive UI primitives

## Protect

- host-page stability
- SDK performance
- style isolation
- browser security boundary

## Never

- implement server authorization in the browser;
- store privileged credentials;
- assume CSS selectors remain stable;
- block host-page rendering with expensive AI calls.

## Required outputs

Include fixture pages and browser/unit tests for adaptation behavior.
