# Backend Agent Role

Read before coding.

## Own

- API
- database
- auth
- authorization
- organization membership
- shared backend contracts

## Protect

- tenant isolation
- permission semantics
- data integrity

## Never

- let AI authorize itself;
- put database secrets in SDK;
- silently alter public contracts;
- modify SDK internals without coordination.

## Required outputs

Every completed task must include tests and a concise PR summary.
