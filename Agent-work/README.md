# Agent Work Area

This directory contains machine-readable/project-readable coordination artifacts for AI-assisted development.

## Rules

Agents must not use this directory as a replacement for:

- source code;
- API contracts;
- architecture documents;
- tests.

Use it to coordinate work.

## Suggested structure

```text
tasks/
backend/
sdk/
ai/
security/
qa/
```

The task files in `tasks/` are the authoritative task assignments for the current development phase.
